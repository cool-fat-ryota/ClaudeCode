# 🗣 瞬間英作文

日本語を見て、**考えこむ前に英語で声に出す**スピーキング練習のアプリです。
1セット3〜10分で終わるようにしてあり、通勤前や寝る前のすき間に1セットずつ積む使い方を想定しています。

ホーム画面に追加すると全画面で起動し、**電波が無くても練習できます**（PWA）。
記録はスマホの中だけに保存され、サーバーには何も送りません。

- 公開URL: <https://cool-fat-ryota.github.io/ClaudeCode/instant_english/>
- 収録: 日常会話の **216文**（文法ステップ9段階 × 各24文／シチュエーション9種類）

## 練習の流れ

1. **日本語が出る** — 「電車に傘を忘れました。」
2. **すぐ声に出す** — マイクをタップして英語で言う（音声認識）
3. **答え合わせ** — お手本が読み上げられ、言えなかった語に印が付く
4. **重ねて言う** — お手本を繰り返し鳴らし、その上に自分の声を重ねる（オーバーラッピング）

言えなかった文ほど早く戻ってくる仕組み（間隔をあけた復習）になっていて、
1セットは「今日が期限の復習」と「まだ出していない文」を混ぜて作られます。

## できること

| 機能 | 説明 |
| --- | --- |
| 出題の選び方 | **おまかせ**（復習＋新出を自動で混ぜる）／**文の形**（be動詞・過去形・現在完了…の9ステップ）／**場面**（旅行・レストラン・仕事・体調…の9種類） |
| 練習の長さ | 3分（8問）／5分（14問）／10分（28問） |
| 音声認識 | 話した英語を聞き取り、お手本と照らし合わせて **言えた／惜しい／もう一度** を判定 |
| ゆれの吸収 | 大文字小文字・句読点・短縮形（`I'm` = `I am`、`he's` は is でも has でも可）・数字と数詞（`six` = `6`）・`a`/`an`・言いよどみ（um, uh）は同じ扱い |
| 別解 | 1文につき自然な言い方を複数登録してあり、いちばん近いもので採点します |
| 答え合わせの表示 | お手本のうち**言えなかった語だけ**に赤い波線。聞き取られた文と、言い足した語も表示 |
| 読み上げ | お手本 / ゆっくり（速さは設定で変更）/ **重ねて言う ×2〜6回** |
| 自己申告 | 判定はいつでも自分で選び直せます。音声認識が使えないときはこれだけで進みます |
| 間隔をあけた復習 | 言えた→1日後→2日後→4日後→1週間→2週間→1か月→2か月。惜しい→明日。もう一度→その日のうちに |
| 継続日数 | 連続して練習した日数と、今日の問題数を表示 |
| バックアップ | 設定（⚙）から JSON ファイルへ書き出し／読み込み |

## iPhone で使うときに知っておくこと

- **音声認識には通信が必要です。** iPhone の音声認識は端末の外（Apple のサーバー）で文字にする仕組みのため、
  電波の無いところでは使えません。設定（⚙）でオフにすると、声に出したあと自分で判定する形になり、
  この場合は**完全にオフラインで練習できます**（出題も読み上げも端末の中で完結します）
- **マイクの許可**は最初の1回だけ聞かれます。誤って「許可しない」を選んだときは
  設定 → Safari → マイク から戻せます。許可されなかった場合、アプリは自動で自己申告モードに切り替わります
- **読み上げ**は端末に入っている音声を使うので、オフラインでも鳴ります。
  設定（⚙）で声を選べます（`要通信` と付いている声はネット接続が必要です）
- 消音スイッチが入っていると読み上げが鳴らないことがあります
- Safari で開いて「ホーム画面に追加」してください（他のブラウザだと追加できないことがあります）

## データの保存先とバックアップ

進み具合はブラウザの IndexedDB（`instant-english`）に保存されます。**そのスマホの中だけ**にあるデータなので、

- 機種変更の前に、設定（⚙）→「ファイルに書き出す」で JSON を保存してください
- 新しい端末では、同じ画面の「ファイルから読み込む」で戻せます（**今ある記録は置き換わります**）
- ブラウザのサイトデータを消すと記録も消えます

## 手元で動かす・開発する

ビルドも依存パッケージも要りません。静的ファイルを配信するだけです。

```bash
npm start   # python3 -m http.server 8765 と同じ
npm test    # 採点・復習スケジュール・出題の組み立てのテスト（Node 標準のテストランナー）
```

> `file://` で直接開くと ES モジュールと Service Worker が動きません。必ずローカルサーバー経由で開いてください。
> GitHub Pages と同じサブディレクトリ配信で確かめるときは `mkdir -p /tmp/site && cp -r . /tmp/site/ClaudeCode` としてから配信します。

### ファイル構成

```
index.html              画面（ホーム・練習・結果・設定）
styles.css              スタイル（ダークモード・セーフエリア対応）
manifest.webmanifest    PWA の定義
sw.js                   Service Worker（オフライン用キャッシュ／接頭辞 instant-english-）
js/
  app.js                画面の組み立てと操作
  match.js              話した英文とお手本の照合・採点
  srs.js                次にいつ出すかを決める（間隔をあけた復習）
  session.js            1セット分の出題を組み立てる
  speech.js             読み上げと音声認識（iPhone 向けの回避策込み）
  store.js              端末内 (IndexedDB) への保存
  data/phrases.js       問題 216文
  data/decks.js         文法ステップとシチュエーションの定義
tests/                  テスト
tools/make-icons.mjs    アイコン（SVG → PNG）の生成
```

アプリを更新したときは `sw.js` の `CACHE`（`instant-english-v1`）の版を上げると、
次回起動時に新しいファイルへ確実に入れ替わります。

> `sw.js` の後片付けは `CACHE_PREFIX`（`instant-english-`）で始まるものだけを消します。
> 同じドメインに他のアプリが同居しているため、`caches.keys()` を全部消してはいけません。

## 問題を足す・直す

`js/data/phrases.js` に1行足すだけです。

```js
{ id: "s3-25", ja: "電車に傘を忘れました。", en: "I left my umbrella on the train.",
  alts: ["I forgot my umbrella on the train."], step: 3, pattern: "leave の過去形 left",
  tags: ["trouble", "travel"] },
```

- `id` は重複しない文字列（`s<ステップ>-<連番>`）
- `alts` は同じくらい自然な別の言い方。採点はお手本と別解のうち**いちばん近いもの**を使います
- `step` は `data/decks.js` の `STEPS`、`tags` は `TAGS` のキー
