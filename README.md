# あわ貯金

衝動買いを「買わない」でこらえるのではなく、**いったん泡に閉じこめて、冷めたら割る**アプリです。
割れた泡はコインになって地面に積もっていきます。

## 使い方

1. ほしくなったら、買う前に **泡にする**。入れるのは**金額と写真だけ**（一言メモは任意）
2. 泡は金額に応じた日数だけ空をふわふわ漂う。その間は割れません
3. 泡をタップすると、**いまの気持ち**（まだ欲しい／ふつう／冷めた）と**メモ**を残せます
4. 冷めたら **泡をわる**。パチンと弾けて、その金額が**コイン**になって下に落ちます
5. コインは**1年ごとにリセット**。前の年の分は「きろく」に残ります

期間は自分で決める必要はありません。金額から自動で決まります。

| 金額 | ふくらんでいる日数 |
| --- | --- |
| 1,000円未満 | 1日 |
| 5,000円未満 | 3日 |
| 20,000円未満 | 7日 |
| 50,000円未満 | 14日 |
| 50,000円以上 | 30日 |

泡の大きさは金額に比例します。高いものほど大きな泡になり、割ったときのコインも大きくなります。

## 画面

- **空**：ふくらみ中の泡。期間が過ぎた泡には「わりごろ」の札がつきます。「冷めた」と記録した泡は輪郭が点線になります
- **地面**：見送って貯まったコイン。タップするとそれが何だったか見られます
- **右上の •••**：今年と過去の年の記録、買ったもの、データの書き出し・読み込み
- 背景のドット絵の動物たちは、コインが増えると跳ねて喜びます

## 写真について

- 泡にするときに「写真をえらぶ」から端末の写真やスクリーンショットを取り込めます。貼り付け（Ctrl / ⌘ + V）も可
- あとから泡をタップして足すこともできます
- 長辺 720px の JPEG に縮小して端末内に保存します。外部のサーバーには送りません
- 商品ページの URL から画像を自動取得することはしていません（サイト側の都合で表示できないうえ、閲覧先が外部に伝わるため）

## 動かし方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

```
open index.html          # macOS
python3 -m http.server   # http://localhost:8000 で開く
```

スマートフォンでは「ホーム画面に追加」をしておくと、ほしくなった瞬間に泡にできます。

## データについて

- データは端末のブラウザ（localStorage）にだけ保存されます
- 機種変更やブラウザのデータ削除で消えるので、「••• > データ > 書き出す」でテキストを保管してください
- 旧バージョン（クールダウン貯金）のデータは、初回起動時に自動で引き継がれます

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 配色・泡やコインの動き（ライト / ダーク両対応） |
| `app.js` | 期間の計算、保存、泡とコインの描画、ドット絵キャラの生成、写真の取り込み |
