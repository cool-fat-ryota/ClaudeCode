# クールダウン貯金

衝動買いを「買わない」で止めるのではなく、**いったん寝かせて、冷めたら見送る**ためのアプリです。
見送った金額はそのまま「貯まった金額」として積み上がります。

## 使い方

1. 欲しいものができたら、買う前に**保留**する（品名・金額・欲しいと思った理由・写真）
2. 金額に応じて**冷却期間**が決まる（高いものほど長く寝かせる）
3. 冷却中はいつでも「**いまの欲しい度**」を 1〜5 で記録できる。推移が折れ線で見えるので、熱が下がったのが自分でわかる
4. 冷却が終わったら「**見送る**」か「買う」を選ぶ
5. 見送った分が**貯まった金額**に加算される。使いみち（目標）を決めるとゲージが伸びる

### 写真について

- 保留するときに「画像を選ぶ」から端末の写真やスクリーンショットを取り込めます。入力欄にそのまま貼り付け（Ctrl / ⌘ + V）もできます。
- 保留したあとでも、カードの「写真を追加」から足せます。サムネイルをタップすると拡大表示になり、差し替え・削除ができます。
- 画像は長辺 720px の JPEG に縮小してから端末内に保存します（1枚あたりおおむね数十KB）。外部のサーバーには一切送りません。
- 商品ページの URL から画像を自動取得することはしていません。取得元サイトの都合で表示できたりできなかったりするうえ、閲覧履歴が外部に漏れるためです。画面を撮って貼るほうが確実です。
- 写真を多く入れるとブラウザの保存容量（およそ5MB）に達することがあります。その場合は保存時にメッセージが出るので、古いものを削除してください。

### 冷却期間のルール

| 金額 | 寝かせる期間 |
| --- | --- |
| 1,000円未満 | 1日 |
| 5,000円未満 | 3日 |
| 20,000円未満 | 7日 |
| 50,000円未満 | 14日 |
| 50,000円以上 | 30日 |

保留するときに自分で期間を選ぶこともできます。

### ふりかえり

- 月ごとに見送った金額のグラフ
- 見送り率、買ったものの平均満足度、カテゴリ別の見送り額
- 買ったものに満足度（1〜5）をつけると、低かったものが「次に効く学び」として残ります

## 動かし方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

```
open index.html          # macOS
python3 -m http.server   # http://localhost:8000 で開く
```

スマートフォンではブラウザの「ホーム画面に追加」をしておくと、思いついたときにすぐ保留できます。

## データについて

- データは端末のブラウザ（localStorage）にだけ保存されます。サーバーには何も送りません。
- 機種変更やブラウザのデータ削除で消えるので、「ふりかえり > データ > 書き出す」でテキストを保管してください。別の端末では「読み込む」で復元できます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 配色・レイアウト（ライト / ダークの両対応） |
| `app.js` | 冷却期間の計算、保存、集計、描画、画像の取り込みと縮小 |
