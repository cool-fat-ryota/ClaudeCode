# 🎤 カラオケ レパートリー帳

カラオケの **レパートリー** と、**次に練習したい曲** を記録するスマホ向けのアプリです。
曲ごとにキー（原キーからの増減）と歌った感想を残せて、YouTube Music のリンクは自動で設定されます。

ホーム画面に追加すると、ふつうのアプリと同じように全画面で起動し、**電波が無くても使えます**（PWA）。
記録はスマホの中だけに保存され、サーバーには何も送りません。

見た目は「ライブハウスのネオン看板」をイメージした暗い配色で、
レパートリーはピンク、練習したい曲はシアンで光ります。

## スマホに入れる

### 1. 公開する（設定済み）

このアプリは [ClaudeCode リポジトリ](https://github.com/cool-fat-ryota/ClaudeCode) の
`karaoke/` に置かれ、GitHub Pages で配信しています。

- URL: `https://cool-fat-ryota.github.io/ClaudeCode/karaoke/`
- 配信の設定は **Settings → Pages** の「Deploy from a branch」
  （`claude/impulse-purchase-app-sif3y5` の `/ (root)`）。push すると1分ほどで反映されます
- 開発用リポジトリは <https://github.com/cool-fat-ryota/karaoke_repertory>（テストと履歴はそちら）。
  直したときは、`index.html` `styles.css` `sw.js` `manifest.webmanifest` `js/` `icons/` `fonts/` を
  両方に反映してください

### 2. ホーム画面に追加する

公開した URL をスマホのブラウザで開いて、

- **iPhone (Safari)**: 共有ボタン（□に↑）→「ホーム画面に追加」
  - Safari で開く必要があります（他のブラウザだと追加できないことがあります）
- **Android (Chrome)**: メニュー（⋮）→「アプリをインストール」／「ホーム画面に追加」

以降はアイコンから起動でき、オフラインでも記録・閲覧できます。

## できること

| 機能 | 説明 |
| --- | --- |
| 曲の記録 | 曲名・アーティスト名・キー・リスト（レパートリー／練習したい）を登録 |
| アーティスト名の補完 | 150組ほどを最初から登録済み。漢字・ひらがな・カタカナ・ローマ字のどれで打っても候補が出ます（例:「よねづ」「yoas」「ヨル」「髭男」） |
| 新しいアーティスト | 候補に無い名前はそのまま登録され、次回から候補に出ます。よみがなを入れておくと、かなでも呼び出せます |
| キーの記録 | 原キーからの増減を −12〜+12 で記録し、「キー −2」のように表示 |
| 歌った感想 | 曲ごとのメモ欄。書いている途中でも自動保存されます |
| 自信度 | ★1〜5。もう一度押すと解除 |
| YouTube Music リンク | 登録時に自動で設定。曲カードから1タップで再生できます |
| 今日歌った | ボタン一つで最後に歌った日を記録 |
| 絞り込み | リストの切り替え、曲名・アーティスト・感想・よみがなでの検索、並び替え |
| バックアップ | 設定（⚙）から JSON ファイルへ書き出し／読み込み |

## データの保存先とバックアップ

記録はブラウザの IndexedDB に保存されます。**そのスマホの中だけ**にあるデータなので、

- 機種変更の前や、たまにバックアップとして、設定（⚙）→「ファイルに書き出す」で JSON を保存してください
- 新しい端末では、同じ画面の「ファイルから読み込む」で戻せます（**今ある記録は置き換わります**）
- ブラウザのサイトデータを消すと記録も消えます

複数の端末で同じ記録を見たい場合は、書き出し／読み込みで移す形になります（自動同期はありません）。

## YouTube Music のリンクについて

曲を登録すると、リンクは次のように決まります。

1. **ふつうの状態**: 曲名とアーティスト名で YouTube Music を検索するリンクを設定します（設定不要・オフラインでも作れます）。
2. **YouTube Data API のキーを設定した場合**: 曲そのもののページ（`https://music.youtube.com/watch?v=...`）を自動で探して設定します。
   設定（⚙）→「YouTube Data API キー」に入力してください。キーは端末内にだけ保存されます。
   キーは [Google Cloud Console](https://console.cloud.google.com/) で YouTube Data API v3 を有効にすると取得できます（無料枠あり）。

- 曲名やアーティスト名を直すと、自動リンクも貼り直されます。
- 自分でリンクを貼った曲は自動更新の対象外になります（編集画面でリンク欄を空にすると自動に戻ります）。
- `https://www.youtube.com/watch?v=...` や `https://youtu.be/...` を貼ると、YouTube Music の形式に変換して保存します。

## 手元で動かす・開発する

サーバーもビルドも不要で、静的ファイルを配信するだけです。

```bash
npm start           # python3 -m http.server 8765 と同じ。 http://127.0.0.1:8765/ を開く
npm test            # ロジックのテスト（Node の標準テストランナー、依存パッケージなし）
```

> `file://` で直接開くと ES モジュールと Service Worker が動きません。必ずローカルサーバー経由で開いてください。

### ファイル構成

```
index.html              画面
styles.css              スタイル（ダークモード・セーフエリア対応）
manifest.webmanifest    PWA の定義（アイコン・起動方法）
sw.js                   Service Worker（オフライン用キャッシュ）
js/
  app.js                画面の組み立てと操作
  model.js              曲データの検証・絞り込み・並び替え・候補の順位付け
  store.js              端末内 (IndexedDB) への保存
  youtube.js            YouTube Music リンクの組み立て・自動取得
  text.js               検索用の文字列正規化（カタカナ→ひらがな など）
  artist-seed.js        最初から入っているアーティスト一覧
icons/                  アプリアイコン
fonts/                  見出し用フォント（Bebas Neue / SIL Open Font License, fonts/OFL.txt）
tests/                  テスト
```

見出しには Bebas Neue（英数字のみ、約14KB）を同梱しています。
日本語は端末のフォント（iPhone なら Hiragino Sans）で表示するため、追加のダウンロードはありません。

アプリを更新したときは `sw.js` の `CACHE` の名前（`karaoke-repertory-v1`）を変えると、
次回起動時に新しいファイルへ確実に入れ替わります。
