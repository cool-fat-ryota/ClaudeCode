      設定

      ホーム画面に追加

      iPhone は Safari の共有ボタン（□に↑）から「ホーム画面に追加」を選ぶと、 アプリとして全画面で起動できます。Android は Chrome のメニュー（⋮）から追加できます。

      YouTube Music のリンク

      通常は曲名とアーティストで検索するリンクを自動設定します。 YouTube Data API のキーを入れると、曲そのもののページを自動で探します（任意）。

      キーはこの端末の中だけに保存されます。

      データのバックアップ

      記録はこの端末の中だけに保存されます。機種変更の前に書き出しておくと安心です。
