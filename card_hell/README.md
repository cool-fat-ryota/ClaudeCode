# カード地獄

クレジットカードの請求でびっくりしないための、**使ったその場で残すだけ**の記録アプリです。
家計簿のように細かくは付けません。入れるのは**金額と分類**の2つだけ。

使うほど画面が熱くなり、予算を超えると背景が地獄になります。
「気づいたら使っていた」を、見た目でわかるようにするのが目的です。

## 使い方

1. カードを切ったら **＋カードを使った** を押し、金額を入れて分類を選ぶ（メモと日時は任意）
2. 上に今の期間の合計が出る。予算に近づくほど背景の温度が上がる
3. **ふりかえり** で、何に使ったかを多い順に見る。前の期間ともくらべられる

よく使う分類は上の丸いボタンに並ぶので、そこから押すと分類を選んだ状態で入力が開きます。

## 画面の温度

| 予算に対して | 画面 |
| --- | --- |
| 〜35% | 白っぽい朝の空。まだ涼しい |
| 〜60% | 夕方の色。少しずつ熱を持ってくる |
| 〜80% | 空が焦げてくる。下から炎が見えはじめる |
| 〜100% | 赤黒い。火の粉が舞う |
| 100%超 | 地獄。画面がゆっくり脈打ち、超過額を突きつけてくる |

端末の「視差効果を減らす（動きを減らす）」を入れていると、炎と火の粉は止まります。

## 反省のための仕組み

- 記録した直後に、その分類の今期の累計を出す（「外食が今期いちばん。すでに ¥23,400 です」）
- **ふりかえり**：分類ごとの金額・件数・割合を多い順に並べる
- 日ごとの棒グラフと、いちばん使った日
- 前の期間との差、分類ごとの増減
- 大きかったもの上位3件
- 上部の「このペースだと期末 ¥◯◯」

## 設定（右上の •••）

- **予算と期間の区切り**：1か月に使ってよい額と、集計の始まる日。カードの締め日に合わせられます
- **分類**：使わない分類を外したり、自分の分類（名前＋絵文字）を足したりできます
- **データ**：JSON で書き出し・読み込み。同じ記録は重ならないように足し合わせます

## データについて

- 記録はこの端末のブラウザ（localStorage、キー `card-hell-v1`）にだけ保存され、外部には送りません
- 機種変更やブラウザのデータ削除で消えます。ときどき「データ > ファイルに書き出す」で保管してください
- `navigator.storage.persist()` で、なるべく消えないように申請しています

## アプリとして入れる（PWA）

- URL: <https://cool-fat-ryota.github.io/ClaudeCode/card_hell/>
- **iPhone / iPad（Safari）**：共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：メニュー → 「アプリをインストール」

追加すると全画面で開き、電波がなくても使えます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 配色と炎・火の粉の動き（色は JS が流し込む） |
| `app.js` | 期間の計算、保存、温度の計算、一覧とふりかえりの描画 |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示などの設定 |
| `sw.js` | オフラインで開くためのキャッシュ（接頭辞 `card-hell-`） |
| `icons/` | アプリアイコン（SVG と、そこから作った PNG） |
| `tools/make-icons.mjs` | SVG から PNG を作り直すスクリプト |

## 手元で動かす

ビルドは要りません。GitHub Pages と同じサブディレクトリ配信で確かめます。

```bash
mkdir -p /tmp/site && cp -r . /tmp/site/ClaudeCode/card_hell
(cd /tmp/site && python3 -m http.server 8765)   # http://127.0.0.1:8765/ClaudeCode/card_hell/
```
